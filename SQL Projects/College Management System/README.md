# College Management System

## Project Overview

This project uses SQL to manage college-related information, including student records, course details, and academic data.

## Database Tables

- **Students:** Contains student information and personal records.
- **Courses:** Contains course details and related information.
- **Enrollments:** Stores information about students enrolled in courses.

## SQL Concepts Used

- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate functions (COUNT, AVG, MAX)
- GROUP BY and HAVING
- JOIN operations

## Key Questions

- How many students are registered in the college?
- Which courses have the highest number of enrollments?
- How many students are enrolled in each course?
- Which courses have no student enrollments?
