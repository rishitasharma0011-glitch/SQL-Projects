## About This Repository

Welcome to my SQL Data Analytics Portfolio. This repository showcases my hands-on projects using SQL to explore structured data, analyse business-related questions, and develop practical database querying skills.

The projects cover different domains, including sales and product analysis, college management, and banking transactions. Each project focuses on applying SQL concepts to retrieve, organise, summarise, and analyse data.

## Projects Overview

### 1. Sales & Product Analysis

**Objective:** Analyse product and sales data to understand product performance, sales quantities, and salesperson performance.

**Key Analysis Areas:**

- Product pricing and product information
- Total quantity sold
- Sales performance by salesperson
- Identification of top-performing salespeople

**SQL Concepts:** Filtering, sorting, aggregate functions, GROUP BY, and HAVING.

### 2. College Management System

**Objective:** Organise and analyse college-related data, including student records, courses, and enrolments.

**Key Analysis Areas:**

- Student records and enrolment information
- Student distribution across courses
- Course enrolment counts
- Identification of courses without enrolments

**SQL Concepts:** Data retrieval, filtering, aggregate functions, GROUP BY, HAVING, and JOIN operations.

### 3. Bank Transaction & Customer System

**Objective:** Analyse banking data related to customers, accounts, and transactions.

**Key Analysis Areas:**

- Transaction amount analysis
- Customer transaction activity
- Account balance analysis
- Identification of accounts with high transaction amounts

**SQL Concepts:** Filtering, sorting, aggregate functions, GROUP BY, HAVING, JOIN operations, and subqueries.
