# Sales & Product Analysis

## Project Overview
This project uses SQL to analyse product and sales data.

## Database Tables
- Products: Contains product names, categories, and prices.
- Sales: Contains sales records, quantities, dates, and salesperson information.

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate functions: SUM, AVG, COUNT, MAX
- GROUP BY and HAVING

## Business Questions
- Which products cost more than a specified amount?
- What is the total quantity sold?
- How much quantity has each salesperson sold?
- Which salesperson sold the highest total quantity?

## Tools Used
- MySQL Workbench
- MySQL
