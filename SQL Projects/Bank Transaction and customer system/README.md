# Bank Transaction & Customer System

## Project Overview

This project uses SQL to manage and analyse banking information, including customer details, account records, and transaction data.

## Database Tables

- **Customers:** Contains customer information and personal records.
- **Accounts:** Stores account details and account balances.
- **Transactions:** Contains transaction records, amounts, dates, and transaction types.

## SQL Concepts Used

- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate functions (SUM, AVG, COUNT, MAX)
- GROUP BY and HAVING
- JOIN operations
- Subqueries

## Key Questions

- What is the total transaction amount?
- Which customers have the highest transaction activity?
- What is the total balance across accounts?
- Which accounts have the highest transaction amounts?
