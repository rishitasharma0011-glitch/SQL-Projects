# Sales & Product Analysis

## Project Overview
This project uses SQL to analyse product information and sales data, with a focus on sales performance and product analysis.

## Database Tables
- **Products:** Contains product names, categories, and prices.
- **Sales:** Contains sales records, quantities, dates, and salesperson information.

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate functions (SUM, AVG, COUNT, MAX)
- GROUP BY and HAVING

## Key Questions
- Which products cost more than a specified amount?
- What is the total quantity sold?
- How much has each salesperson sold in terms of quantity?
- Which salesperson has the highest total quantity sold?

## Tools Used
- MySQL Workbench
- MySQL
